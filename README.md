# Duende Software - Blog Samples

This repository contains the companion code that supports articles on the [Duende Software blog](https://duendesoftware.com/blog) and other point-in-time content sources. Please note that the code in this repository is provided strictly "as-is" at the time of publishing the related content. It is typically not maintained and will not be updated to newer dependency versions, framework releases, or security patches over time.
